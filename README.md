## Construir el contenedor

2. Dar permisos de ejecución al instalador.

Ve a la dirección donde has descargado el proyecto git y entra en él, deberia haber un archivo llamado "install.sh".

```
chmod ugo+x ./install.sh
```

3. Ejecutar el código de instalación.

El ejecutable necesita tres parametros que son los nombre de la imagen dockerfile, del volumen y del contenedor. 

```
bash ./install.sh nombre_imagen nombre_volumen nombre_contenedor
```
